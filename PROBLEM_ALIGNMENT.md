## Honest gaps and operating limits

- The configured data.gov.in resource has not supplied an explicit AQI field with verifiable station/time evidence in the inspected live records. AIRWISE therefore displays no official index in those cases. A supported source that supplies an explicit, verifiable index is required to complete live official-AQI coverage.
- CPCB pagination or rate limiting can make a city snapshot incomplete. The adapter fails closed rather than selecting a station from a partial dataset.
- OpenAQ is supplementary and needs coordinates plus an API key. Some nearby stations return stale measurements; these are marked historical.
- A provider configured flag is not proof of working credentials or model availability. Current live provider readiness must be checked separately and only when an external request is authorized.
- Recommendation logic is practical general guidance, not an emissions calculator or health-risk estimator.
